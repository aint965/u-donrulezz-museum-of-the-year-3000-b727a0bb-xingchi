# Museum of the Year 3000

A single-line museum label for the make.fun competition
[Museum of the Year 3000](https://make.fun/bounty/u-donrulezz-museum-of-the-year-3000-b727a0bb):
the label a museum in the year 3000 places beside an ordinary object from
today — a toothbrush, solemnly misread as a wand for scrubbing the bones
inside the human mouth.

`main.py` writes that one label to `/output/entry.txt` (or
`$OUTPUT_DIR/entry.txt`).
